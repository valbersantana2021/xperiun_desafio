# Xperiun – Desafios de Power BI

Portfólio de resolução dos 10 desafios de dashboards da Xperiun, por **Valber Santana · Data Mining**.
Cada desafio documenta as perguntas de negócio, o modelo de dados e as soluções aplicadas (DAX, Power Query, layout).

## Estrutura

```
desafios/
  _template/            Tema e chassi reutilizáveis (identidade Data Mining)
  001_Healthlab/ ... 010_Vertex_Tennis/
    doc/      Requisitos e documentação da solução
    db/       Dados de origem (não versionados)
    assets/   Tema JSON e materiais visuais
    pbix/     Projeto Power BI (PBIP/PBIR/TMDL)
    sql/      Consultas de apoio
    mockup/   Layouts
```
